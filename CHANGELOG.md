# Changelog

Notable changes to Contribution Leaderboard will be recorded here. This project has not yet published a release.

## Unreleased

### Added

- TypeScript GitHub Action for scheduled Discord contribution leaderboards.
- Daily, weekly, monthly, quarterly, and anchored custom-month posting schedules.
- Independent previous-period, day-to-date, week-to-date, anchored multi-week, month-to-date, and all-time score windows, with scores recalculated from GitHub on each run.
- Configurable scoring for merged pull requests, issues opened, and issues manually completed; automatic PR and commit closures do not earn extra completion points.
- Medal ranks, contributor links and counts, a thank-you message, and a logo thumbnail in the Discord embed.
- Dry runs, workflow summaries, outputs, configurable exclusions, and an example workflow.
- Automated checks, a step-by-step design document, and contribution guidelines.
- MIT license and an illustrative Discord post preview.
